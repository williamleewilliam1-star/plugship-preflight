Privacy Policy

Effective September 28, 2026. PlugShip Preflight is a local developer tool for reviewing plugin repositories before directory submission.

Data processed

PlugShip reads files inside the plugin directory selected by the user. Those files may contain source code, documentation, configuration, and incidental personal information such as author names or email addresses.

Data transmission

The deterministic scanner makes no network requests and does not transmit repository contents or scan results to BABYDOV or third parties. If the optional Claude validation mode is used, PlugShip invokes the locally installed Claude Code validator; PlugShip itself adds no additional transmission.

Storage and retention

PlugShip has no server-side database and does not retain user repository contents. Reports are written only to a local path selected by the user.

Credentials

PlugShip is designed to flag likely accidentally committed credentials. It does not intentionally collect, store, or transmit credentials.

Children

PlugShip is a developer tool and is not intended for users under 18.

Contact

Support and privacy questions can be opened through the public GitHub issue tracker.
